## 5. Topic: Digital Productivity / Career
**Viral Title:** Stop Using Folders. Use the "PARA" Method.

**5-second Hook:** 
"Your digital life is a mess because you're organizing it like it's 1995. Stop using random folders and use the PARA method instead."

**60-second Script:**
*   **(0:05-0:15):** Most people have hundreds of files they never look at. Tiago Forte’s PARA method simplifies everything into just four categories.
*   **(0:15-0:30):** 1. **Projects:** Things with a deadline. 2. **Areas:** Ongoing responsibilities (like health or finance).
*   **(0:30-0:45):** 3. **Resources:** Topics you're interested in for the future. 4. **Archives:** Everything else that’s finished.
*   **(0:45-0:55):** When a project is done, you slide it to Archives. If you start a new hobby, it goes into Resources. 
*   **(0:55-1:00):** Your brain is for *having* ideas, not *holding* them. Organize for action, not for storage.

**Call To Action:**
